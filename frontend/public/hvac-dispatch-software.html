EPA 608 Certification Dispatch Filtering

Under 40 CFR Part 82, any technician who opens a refrigerant circuit must hold an EPA 608 certification appropriate to the system type. Type I covers small appliances (sealed systems under 5 lbs). Type II covers high-pressure systems like R-410A, R-22, and R-32 residential and commercial equipment. Type III covers low-pressure centrifugal chillers. Universal certification covers all types. Dispatching an uncertified technician to a refrigerant job is a federal violation carrying fines up to $44,539 per day per violation.

FieldZenPro stores each technician's EPA 608 certification type and certification card number. When a job is tagged as requiring refrigerant work, the dispatch system automatically filters the available technician pool to show only those with the required certification type. A new dispatcher cannot accidentally assign a Type I-only technician to a commercial RTU job requiring Type II certification -- the system prevents it before the error happens.
